# LogiBricks brand sources

`logibricks-desktop-dark-1024.png` is the approved v2 raster master. The macOS generator scales its 896 px plate to 824 px on a 1024 px canvas. Keep the complete image so the relief and shadows stay aligned.

`LogiBricks-Workspace-Design-History-2026-11-10.zip` preserves the complete v1 and v2 design folders, their original archives, guides, fonts, licenses, source scripts, and the final macOS assets. Its internal SHA256SUMS lists every source file. Python bytecode is excluded.

The archive keeps frozen design bytes separate from source formatting. The current application code and resources remain ordinary files in packages/brand, build, apps/mobile, and apps/auth-api. The archive is not included in application packages.

Current settings use 12 px text, 18 px line height, a 16 px optical mark, and a 6 px gap. Company package signing and release publication remain separate from these source assets.
